# 탐험대 미션 (PRD)

작성일: 2026-11-11 · 상태: 기획 확정, 구현 시작

## 한 줄 소개
초등 2학년 두 아들이 **하루 15분** 안에 받아쓰기·영어 단어·지식 퀴즈 미션을 깨고 카드를 모으는 탐험대 게임.
공부 앱처럼 보이지 않고, 미션이 끝나면 스스로 닫힌다.

## 누가 쓰나
- 아들 둘 (초2). 삼성 안드로이드 패드의 브라우저로 연다. 사이트 허용 목록에 `mukaa1111.github.io` 하나만 추가.
- 부모(나): 금요일에 폴리 교재 단어장(A4) 사진을 찍어 "이번 주 단어 반영해줘"라고 하면 영어 미션이 바뀐다. 비밀번호로 잠금 해제.

## 핵심 기능 (5개)
1. **오늘의 미션 3개** — ① 받아쓰기 5문장(1단계는 맞는 글자 고르기 3지선다, 2단계는 직접 입력. 패드 음성으로 읽어 줌) ② 영어 단어 10개(듣고 고르기·그림 없이 뜻 맞히기·뒤집기 카드) ③ 지식 퀴즈 10문제(공룡·우주과학·한국사·세계 도시와 나라·위인 중 그날 묶음).
   미션을 다 깨면 **카드 1장**을 뽑는다 (공룡·행성·탐험가 카드, 등급 있음). 카드첩에 쌓인다.
2. **형제 배틀** — 한 패드로 번갈아 지식 퀴즈 10문제. 점수판, 승자 트로피. 책에서 서로 퀴즈 내던 놀이를 화면으로.
3. **보상 미니게임 3분** — 미션 완료 뒤에만 열림. 2048, 기억력 카드 중 하나. 3분 타이머가 끝나면 닫힘.
4. **하루 잠금** — 미션 완료 + 보상이 끝나면 "오늘 탐험 완료! 내일 새 카드" 화면. 날짜가 바뀌면 자동으로 열림. 부모 비밀번호(4자리)로만 다시 열 수 있다. 저장은 패드 브라우저 안에만(localStorage).
5. **데이터 파일로 운영** — 문제는 `data/` 안 js 파일 3개(받아쓰기·영어·퀴즈). 금요일 단어장 사진 → `data/english.js` 교체. "공룡 문제 더 넣어줘"도 파일 한 줄.

## 재미 요소 (초2 남아 기준)
큰 버튼, 정답 폭죽, 콤보 카운터, 효과음(정답·오답·카드 뽑기), 카드 등급(일반·희귀·전설)과 뽑기 연출, 연속 출석 불꽃, 두 아이 각자 이름과 카드첩.

## 어떻게 돌아가나 (가장 단순한 방식)
- **HTML 한 장 + js 데이터 파일**, GitHub Pages → 이유: "주말 뭐하지?"와 같은 방식이라 올리는 법을 이미 안다. 서버·로그인 없음.
- **읽어주기는 패드 내장 음성(Web Speech API)** → 이유: 음성 파일을 만들 필요가 없다. 안 되는 기기면 글자로 보여 준다.
- **저장은 localStorage** → 이유: 계정 없이 아이별 진행·카드첩을 패드 안에 둔다. 패드를 바꾸면 사라지는 건 감수.

## 이번엔 안 할 것
- 로그인·클라우드 저장, 두 패드 간 동기화
- 부모용 통계 화면 (카드첩 수가 곧 기록)
- 그림·사진 문제 (글자와 이모지만)
- 영어 발음 평가, 음성 인식
- 광고·외부 링크 (허용 목록 때문에 외부 요청 0)

## 완료 기준
- 패드에서 주소를 열어 아이 이름을 고르고, 미션 3개를 15분 안에 끝내면 카드가 뽑히고 잠긴다.
- 금요일 단어장 사진을 주면 10분 안에 영어 미션이 바뀐다.
- 아이들이 "내일 또 하자"고 한다.
