## 받아쓰기 급수 바꾸기
- "받아쓰기 4급으로 바꿔줘" → `data/dictation.js`의 `current` 숫자를 바꾸고, **음성을 다시 만든다** (아래). 음성은 지금 급수와 그보다 낮은 급만 만들어 두기 때문이다.
- 학교 급수표(2-2학기 1~16급)는 11/13에 모두 반영했다. 급마다 급수표 10문장 + 비슷한 난이도 연습 5문장.

## 받아쓰기 문장을 고치거나 보탰을 때 (음성 다시 만들기)
받아쓰기는 패드 음성이 아니라 미리 만든 한국어 음성 파일로 읽어 줍니다. 문장을 바꾸면 Claude에게 "받아쓰기 음성 다시 만들어줘"라고 하면 됩니다.
(하는 일: `node tools/make-dict-audio.js` → `powershell -File tools/make-dict-audio.ps1` → 올리기. 이 PC의 Windows 한국어 음성 '혜미'를 씁니다.)

**음성 파일 기준 (무겁지 않게)**
- 형식은 16kHz · 16bit · 모노 WAV로 고정. 11kHz로 낮추면 ㅅ·ㅊ·ㅆ이 뭉개져 받아쓰기에 맞지 않는다.
- 전체 15MB 안쪽으로 유지한다. 16급 전체(239문장)는 20.1MB라서 넘는다. 지금은 1~4급 60문장 (문장당 약 84KB). 넘으면 스크립트가 경고를 낸다.
- 그래서 `tools/make-dict-audio.js`는 **지금 급수 + 그보다 낮은 급(복습분)** 만 목록에 넣는다. 12급쯤부터 15MB에 가까워지니, 그때는 아주 낮은 급을 빼는 것을 생각한다.
- 패드는 재생하는 문장만 그때 내려받는다. 미리 전부 불러오는 코드는 넣지 않는다.
- 이미 만든 파일은 다시 만들지 않는다 (같은 파일을 또 올리면 저장소만 무거워진다).
