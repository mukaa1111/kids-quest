# 탐험대 미션 — 사용 안내

초등 2학년 두 아들이 하루 15분, 받아쓰기·영어 단어·지식 퀴즈 미션을 깨고 카드를 모으는 게임이에요.

## 여는 법
- 패드 브라우저에서 https://mukaa1111.github.io/kids-quest/ 를 열어요. 사이트 허용 목록에 `mukaa1111.github.io`를 추가해 두면 돼요.
- 홈 화면에 추가하면 앱처럼 열려요 (Chrome 메뉴 ⋮ → "홈 화면에 추가").
- 대원 이름은 룰루·랄라로 들어 있어요 (부모님 메뉴에서 바꿀 수 있음). 진행 기록과 카드첩은 그 패드 안에만 저장돼요.

## 하루 흐름
1. 대원 고르기 → 오늘 미션 3개: ✏️ 받아쓰기 5문장(이번 급수 3 + 복습 2) · 🔤 영어 10단어 · 🧠 지식 퀴즈 10문제 (주제 6개 중 직접 고름)
   - 한 번 나온 문제는 기억해 두고, 안 나온 문제부터 냅니다. 다 나오면 처음부터.
2. 다 깨면 🎁 카드 한 장 (일반 70% · 희귀 25% · 전설 5%)
3. 🎮 보상 게임, 모두 합쳐 3분 (두더지 잡기 · 풍선 터뜨리기 · 기억력 카드 · 숫자 합치기 2048). 게임을 바꿔도 시간은 이어집니다.
4. "오늘 탐험 완료" 잠금. 내일 새 미션과 새 카드.
- ⚔️ 형제 배틀: 하루 한 번, 둘이 번갈아 10문제.
- 📊 기록: 연속 일수, 탐험한 날, 카드 수, 배틀 승수, 최근 14일 미션 점수와 그날 카드. 부모님 메뉴에서도 오늘 점수가 보여요.
- 🏅 배지 20개: 첫 탐험, 연속 3·7·14일, 미션 만점, 카드 5·10·20·30장, 전설 카드, 세트 완성, 배틀 승리. 따는 순간 알림이 떠요.
- 🔒 부모님 (비밀번호 **2468**): 오늘 미션 처음부터 다시, 잠금만 풀기, 보상 게임 켜고 끄기, 이름 바꾸기, 배틀 다시 열기, 나온 문제 기록 지우기.

## 파일
| 파일 | 뭐 하는 파일인가 |
|---|---|
| `index.html` | 게임 화면 전부. 건드릴 일 거의 없어요. |
| `data/dictation.js` | 받아쓰기. `current`가 이번 주 급수(지금 3). 2학기 1~10급, 급마다 10문장. 학교 급수표와 다른 연습 문장이에요. |
| `data/english.js` | 이번 주 영어 단어. 금요일에 폴리 단어장 사진을 주면 교체. |
| `data/quiz.js` · `data/quiz2.js` | 지식 퀴즈 6묶음 350문제 (공룡·우주와 과학·한국사·세계 도시와 나라·위인 각 60쯤, 스포츠 스타 45). 정답은 항상 첫 번째 보기(화면에서 섞음). 새 문제는 quiz2.js에 보탭니다. |
| `data/dict-audio.js` · `sounds/dict/` | 받아쓰기 문장을 읽어 주는 한국어 음성 파일(138개)과 그 목록. 자동으로 만든 것. |
| `tools/` | `check-data.js`(문제 검사), `make-dict-audio.js`·`.ps1`(받아쓰기 음성 만들기) |
| `data/cards.js` | 카드 30장(공룡·우주·탐험가). |
| `docs/PRD.md` · `docs/PLAN.md` | 기획과 만들 순서 |

## 자주 쓰는 말 (Claude에게)
- "이번 주 영어 단어 반영해줘" (+ 단어장 사진) → `data/english.js` 교체 후 올리기
- "받아쓰기 4급으로 바꿔줘" → `current` 숫자만 바꿈
- "학교 급수표 3급 반영해줘" (+ 사진) → 그 급 문장 10개 교체
- "공룡 문제 10개 더 넣어줘" / "카드 더 만들어줘"
- "GitHub에 올려줘" → 패드 주소에 반영 (1~2분)
